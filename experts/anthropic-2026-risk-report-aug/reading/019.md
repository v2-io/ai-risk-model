"Covered models" defined: Claude Mythos 5 and Model 2. Model 2 passed the pre-internal-deployment review (§2.18) but was less used/evaluated; "we expect Model 2 to have broadly comparable capabilities and propensities to Mythos 5."

**Differed / small seam:** §1.4 says Model 2 is "somewhat more capable than Mythos 5", "a noticeable improvement … for many tasks relevant to internal use". Here: "broadly comparable capabilities and propensities". Not contradictory (somewhat more ⊂ broadly comparable), but the emphasis shifts with the argumentative need: in §1.4 Model 2's extra capability is acknowledged; in §2, comparability lets Mythos 5's evidence carry over to Model 2. An expert should note that Model 2's alignment evidence is largely borrowed from Mythos 5 via this comparability assumption, plus the pre-internal-deployment review.

Wandering: "covered models" is a scope term that varies by section (here two models; CB covers all models). A fork must never assume "covered models" means the same set across sections.
