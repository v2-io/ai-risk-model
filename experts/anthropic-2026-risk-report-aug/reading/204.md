# Unit 204 — §4.5.8.2.1 Unauthorized Mythos Preview access on human-feedback platforms, L2610–2620, pp.147–148

- Separated from Appendix 6.5 because it involved **deliberate unauthorised access by external parties** to one of the most capable models, running without blocking bio classifiers (see §4.5.8.2.2).
- **April 2026**, after an external report: a small number of contractors at data-labelling vendors exploited a platform flaw to obtain an API key giving out-of-scope model access, including **Mythos Preview**. Access path usable for **several weeks**, ~**two weeks** with Mythos Preview available. **Contained within 90 minutes** of learning (systems offline, vendor credentials disabled); vector closed the same day.
- Assessed low risk: only unsafeguarded model conversations accessed; **no weights accessed, no customer data exposed, no breach of Anthropic's networks/core systems**; via the third-party vendor environment, not the production API; all traffic on the key reviewed — no significant CB-threat-model risk found.
- New/strengthened controls (§4.5.5.3.3); vendor access restored for public and lower-risk unreleased models.

Differed: detection came from an **external report**, not Anthropic's own monitoring. Containment was fast once known; detection took weeks.

Wandering: this incident fits the pattern across the report: external parties surface Anthropic's failures (AISI's cyber incident; AISI's jailbreaks; this external report; HF/OpenAI's disclosure affecting the paradigm). Anthropic's internal detection is strong after the fact (traffic reviewed, contained in 90 minutes) and weaker at first detection. For the project: a recorded risk event with timeline fields (window of exposure ~weeks; model exposure ~2 weeks; time-to-contain 90 minutes; detection source external).

Insider-adjacent actors (contractors) acting deliberately is the §3.10 insider standard tested in practice at the supply-chain periphery. The access gained was to an unsafeguarded frontier model for ~2 weeks — the configuration CB-2's expert-uplift estimate (unit 172) concerns. The report's review found no CB-relevant misuse in the traffic.
