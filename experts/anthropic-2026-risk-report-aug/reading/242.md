# Unit 242 — §6.4.1 Weight security overview, L3068–3086, pp.176–177

- A security programme protecting **"ASL-3 model weights"** against most **non-state** attackers (cybercriminals, hacktivists, corporate espionage); six attack-vector categories (endpoint, supply chain, physical, cloud infrastructure, privilege escalation, exfiltration); defence in depth (preventive, detective, responsive); aligned with SOC 2 Type 2, ISO 27001, ISO 42001, extended for AI weights.
- **Out of scope for ASL-3: sophisticated insiders and nation-state attackers** "with capabilities like novel zero-day attack chains"; beyond current achievement.
- **Three worsening trends:** (1) a growing attack surface (new compute across providers, uneven maturity); (2) **capabilities improve faster than defences mature** — the sophistication of motivated adversaries grows faster than that of adversaries reliably stopped; (3) **rising incentive to steal weights specifically, because legitimate-access safeguards are tightening** (customer verification, ZDR limits, monitoring of high-trust arrangements, anti-distillation, limits on frontier-AI-development use) — closing other routes to safeguard-free access pushes determined actors toward theft.
- The gap between motivated and defensible attackers "is at risk of widening".

Differed: **"ASL-3" is used again**, in the appendix's own voice, despite §4.5's statement that the report no longer uses ASL terminology (unit 174). So the retirement is incomplete: the RSP's CB-2 clause (unit 211) and this appendix still say ASL-3 (here as a *security* standard for weights). An expert should state precisely: *the report says it no longer uses ASL terminology for capability and safeguard levels, yet "ASL-3" survives in the quoted RSP CB-2 mitigation and in the weight-security appendix as a security scope.* A lexicon must not treat "ASL-3" as gone from Anthropic's August 2026 vocabulary.

Wandering: **trend (3) is a lovely, uncomfortable systems insight:** each safeguard on legitimate access displaces adversary effort toward weight theft — a control that raises risk elsewhere by closing an easier route. The report states it plainly. For the project's causal chain: control → displacement → raised likelihood of a different risk event. One of the clearest examples of control interaction in the source.

Trend (2) generalises the report's recurring theme (capability outpacing mitigation: §3 "eyes on everything" by 2027; §4 no state-robust security in time) into a security law: the attacker frontier moves with capability. Together with §4.8's admission, an expert can summarise Anthropic's security position as: *robust against non-state actors (by its account); not against sophisticated insiders or nation-states; gap likely widening.*
