# Unit 78 — Pathway 3: code backdoors, L1158–1160, p.66

Complex, reversible like pathway 2; particular challenge: confidence in having found *all* backdoors could be "time consuming and resource intensive" once misalignment is discovered; "we would invest the resources necessary if required."

Differed: no mention of PR review here (it's in the appendix, §2.23.2.3). The pathway note is about remediation cost, not prevention.

Wandering: "Claude now authors a large majority of the code merged into our production codebases" (Table 1.2.B). If evidence of misalignment surfaced, the audit surface would be most of the codebase. "Invest the resources necessary" is a commitment whose cost scales with Claude's share of the code — and auditing would itself likely use Claude models (possibly the suspect ones, or weaker trusted ones). The remediation plan inherits the trust problem. The report doesn't address who audits the code if the coding model is suspect. A question worth putting to an expert.
