# Unit 197 — §4.5.5.3.3 Pre-deployment access, L2533–2553, pp.143–144

Three categories with pre-release access (sometimes slightly earlier snapshots, similar or lower capability):
- **External testers**: classifiers on, except a small number of trusted testers (generally <10) testing dangerous bio capabilities; time-limited.
- **Early access program (EAP) users**: classifiers on, often early untested versions (EAP usage is itself safeguard-testing evidence); time-limited.
- **Human feedback contractors** via outside data vendors: Anthropic doesn't vet individual contractors (vendor's job) but has a risk-based vendor-access assessment (model sensitivity × interactivity), requires identity/background checks per worker, endpoint security, phishing-resistant MFA. Most access with bio classifiers on; vendors with strongest controls get safeguards-exempt/higher-risk models per project — controls "would likely not be robust against a well-resourced threat actor making a concerted effort". **Historically vetting was much weaker**; vendor-related access incidents (§4.5.8.2) → increased monitoring and enforcement (fn 73).

Differed: the human-feedback-vendor channel is the weak link — a supply chain of contractors whose individuals Anthropic doesn't vet, with access to unreleased and sometimes safeguard-exempt models. And the report concedes it wouldn't stop a concerted well-resourced attacker.

Wandering: this sets up the two incidents in the TOC — unauthorised Mythos Preview access on human-feedback platforms, and all vendor traffic run without blocking bio classifiers (the year-long gap behind CB-1's raised rating). The vendor channel is where the report's CB safeguards actually failed this period. For the project: a supply-chain access path (developer → data vendor → contractor) as a risk-event locus; and an example where the *training pipeline's* human-data supply creates a misuse surface. An expert asked "where did Anthropic's CB safeguards fail?" should start here.

"Not robust against a well-resourced threat actor" — the CB-2 actor profile (millions of dollars, PhDs) is precisely a well-resourced actor. A concerted effort via a contractor would be a plausible route to a safeguard-exempt model. The report states the weakness; it doesn't connect it to CB-2's actor definition. I do.
