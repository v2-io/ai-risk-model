# Unit 239 — §6.2 [Appendix redacted], L3058–3060, p.176

Describes the **criteria for the blocking bioclassifier exemption policy**; redacted for security reasons.

Differed: the redacted appendix's *subject* is disclosed. So the exemption policy (§4.5.5.2, "criteria largely unchanged") has public process features (manual vetting, security review, monthly reassessment, short-lived credentials) and private criteria. An expert asked "who qualifies for a bio exemption?" can give only the process, not the criteria.
