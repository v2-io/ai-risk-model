# Unit 79 — Pathway 4: training-data poisoning, L1162–1164, p.66

Similar profile to pathway 3: effective poisoning is complex (evade data reviews, instil behaviour that evades future assessments) → extensive reasoning → monitoring applies; reversible if discovered "within a reasonable timeframe".

Differed: nothing new. 

Wandering: "Reversible within a reasonable timeframe" — for poisoning, the critical time is the training run of the next model. Once a model is trained on poisoned data and deployed, reversal means retraining. So the deadline is concrete: detection must precede training (or deployment) of the successor. The report's reversibility frame fits pathway 4 best of all, with a sharp clock.

One gap I note, not the report's: unit 74's fn 14 classified misalignment passed from a prior model via generated data as *engineered* (Claim 8) if foreseeable. Pathway 4 is the intentional version by a misaligned current model. Unintentional transmission (a misaligned model's synthetic data shaping its successor without intent) falls between — naturally-emerging in the successor, not a "poisoning" act. The §5.2.6 alignment-faking dataset failure is a human-process cousin of this.
