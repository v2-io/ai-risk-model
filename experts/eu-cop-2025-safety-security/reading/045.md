# Unit 45 · L378–380 · p.18: Measure 6.1, Security Goal

**What it held.** "Signatories will define a goal that specifies the threat actors that their security mitigations are intended to protect against ("**Security Goal**"), including **non-state external threats, insider threats, and other expected threat actors**, taking into account at least the current and expected capabilities of their models."

**What differed.** Verbatim what I predicted. Memory. So the clause-level scrutiny has to come from noticing what's *not* there.

**Wandering.**
- **State actors aren't named.** Non-state external threats and insider threats must be covered; state actors fall under "other expected threat actors", if expected. So the Code doesn't require every signatory to defend against nation-state attackers. That's a significant and probably negotiated omission. Nation-state theft of frontier weights is the threat security researchers worry about most (RAND's SL4–SL5). The Code's minimum is non-state + insider. Whether a signatory "expects" state actors is for it to say, in its Security Goal; the AI Office could argue it should. A fork asked "does the Code require protection against nation-state attackers?" should say: not by name; state actors are covered only as "other expected threat actors".
- **"Security Goal" is a defined term**, set by the signatory. Same architecture as acceptance criteria: the signatory defines the target; the Code constrains its form (threat actors, taking into account capabilities).
- **"Current and expected capabilities"**: forward-looking again. A model expected to reach a higher tier needs a security goal set for that future.
- **Threat-actor framing** rather than control-level framing (e.g. "SL3"). The Code defines security by *whom* you defend against, not *how much* control you have. That's the RAND framing (security levels defined by attacker capability), stripped of the levels.

**Questions to keep.**
- "What's the Security Goal?" M6.1: the signatory-defined goal specifying "the threat actors that their security mitigations are intended to protect against", "including non-state external threats, insider threats, and other expected threat actors".
- Should be asked but might not be: "Must signatories protect against state actors?" Not by name.

**Prediction for unit 46.** Measure 6.2, Appropriate security mitigations: Signatories will implement appropriate security mitigations to meet the Security Goal, including those in Appendix 4 (if I recall, a long list: general security, protection of unreleased weights, assuring access controls, insider threat screening, red-teaming / penetration testing, ...). A clause allowing deviations from Appendix 4 with alternative measures that achieve the goal. Possibly staging: "until the model is placed on the market… at least…".
