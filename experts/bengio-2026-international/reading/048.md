# 048 · L665–675 · p.24 · "Updates on AI agents"

**Predicted:** policy shaping, or challenges and gaps. **Got:** a second "Updates on…" block, on agents, and with it a third characterisation of AI agents.

- **The figure text (Figure 1.3's labels): "AI agent: system capable of operating with little oversight and direction".** Components: AI model, memory tool, web browsing tool, computer use tool, iterative reasoning (chain of thought); input = a natural-language request; output = code.
- **The prose definition:** "AI agents are **designed to pursue goals**, which are often **specified by users in natural language**. To achieve these goals, they are given access to tools". So: (goal-pursuit + user-specified goals + tools). With 033 (limited oversight) and 047 (configured to plan, reason, use tools), IASR's agent concept is a *cluster*: goal-pursuit, tool access, planning and reasoning, and reduced oversight. The pieces recur, the combination varies. **Lexicon proposal:** `iasr:ai-agent` as a cluster definition; the oversight criterion is the risk-relevant one, and the tool and goal criteria are the technical one.
- **'scaffolding'**, the second definition: "**These tools and the code used to combine them with the model**". 043 said "additional software built around general-purpose AI models that allows them to plan ahead, pursue goals, and interact with the world". Consistent: scaffolding = tools + glue code. The model is the "'brain'" (in quotes, a metaphor the report uses for the figure).
- "pursue goals with **much less oversight or assistance from humans**". The oversight criterion again, as a consequence of scaffolding.
- **Manus AI** is named as "popular". **Online purchases** among its tasks: agents with payment ability. A risk vector (fraud, unauthorised transactions) that the report might pick up in 2.2.1.
- **The doubling claim:** "the **complexity** of software benchmark tasks that AI agents can accomplish doubles approximately **every seven months**". That's METR's time-horizon result, but METR measures the *human time* a task takes, not "complexity". Paraphrasing length as "complexity" is a small imprecision; 1.2 will presumably state the metric properly (see 023: "reliably … half an hour"). Watch for consistency between "seven months" and the 10-minute → 30-minute change in one year (023). 10 → 30 minutes in a year is a tripling, about a 7.6-month doubling. Consistent.
- "multi-agent systems" is mentioned in passing.
- "**Experts argue** that increasingly capable AI agents will give rise to both major opportunities and risks". Attributed, not asserted. The report distances itself from the claim by attribution.
