# Unit 184 · L264 · p.10

> (C) Harm caused by a foundation model in combination with other software where the foundation model did not materially contribute to the harm.

## What differed

The nouns are consistently "foundation". The connective has changed, though:

- TFAIA (c)(2)(C): "… in combination with other software **if** the frontier model did not materially contribute …"
- Labor Code (a)(2)(C): "… in combination with other software **where** the foundation model did not materially contribute …"

## Wandering

- **This is the second piece of stylistic drift**, after (B)'s "if committed" in u179. "If" and "where" mean the same thing here. Two drifts, both small, both in the copy. The likely history is that one version was polished and the other wasn't, or that they were revised at different times in the amendment process. Version history (the next reading Joseph mentioned) could show which came first.
- Tally, Labor Code §1107(a) against TFAIA §22757.11(c):
  - substantive: frontier → foundation, consistently (stem ×2, (2)(A) subject, (2)(C) ×2);
  - stylistic: (B) "if the conduct had been committed" → "if committed"; (2)(C) "if" → "where";
  - identical: (A), (C), (2) stem, (2)(B).
- Next comes whatever else §1107 defines. If it includes an equity exclusion like §22757.16, the scope becomes the same as the TFAIA's except for the model noun.
