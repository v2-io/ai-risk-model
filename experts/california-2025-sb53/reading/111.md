# Unit 111 · L178 · p.7

> (3) A frontier developer that discovers information about a critical safety incident after filing the initial report required by this subdivision may file an amended report.

## What differed

My first prediction, nearly verbatim.

## Wandering

- **Amendment is optional.** "*May* file an amended report", not "shall". So a developer who later learns its incident report was incomplete or wrong has **no duty to correct it**. Does the false-statement rule (e) fill the gap? An initial report made in good faith and reasonably is protected by the safe harbour. If the developer later learns it was false and says nothing, the original statement doesn't become a new violation (no new statement is made). So **SB 53 has no duty to correct incident reports.** It's a real gap for an information-gathering regime, where later information is often the important part (the scale of a weight leak, the true cause of a loss of control).
- "**The initial report required by this subdivision**": "this subdivision" is (c), which contains both the 15-day OES report and the 24-hour disclosure. So the "initial report" could be either. It slightly supports reading A from u110 (the 24-hour disclosure counts as *the* report in imminent cases), or just treats both as reports. Still ambiguous.
- "**Discovers information about**": a lower bar than discovering an incident. Any new information qualifies for an optional amendment.
