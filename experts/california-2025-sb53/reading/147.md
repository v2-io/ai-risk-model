## Wandering

- **What is named "CalCompute"?** "A framework for the creation of a public cloud computing cluster to be known as 'CalCompute'": the *cluster* is to be known as CalCompute. The cluster doesn't exist. The consortium develops a *framework* for creating it. So "CalCompute" names a hypothetical object, and SB 53 creates a consortium to plan it. Unit 12's point, confirmed in operative text.
- "**There is hereby established**": the consortium is established now, by the act. But the digest (u12) said the provisions are "operative only upon an appropriation". So "hereby established" is subject to an operative-date clause somewhere in this section. The consortium is established on paper and operative only when funded.
- **A second, different "framework".** "A framework for the creation of a public cloud computing cluster": this "framework" is a plan for infrastructure, completely different from the TFAIA's "frontier AI framework" (a risk-management document). Same word, two meanings, one bill. **Lexicon: *framework* (CalCompute: an infrastructure plan) ≠ *frontier AI framework* (TFAIA: a catastrophic-risk protocol document).** A keyword search for "framework" in SB 53 would mix them, and a careless extractor might merge them.
- "Public cloud computing cluster" is public infrastructure, cloud-delivered.
