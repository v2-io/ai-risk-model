# Unit 43 · L100 · p.4

> (B) Engaging in conduct with no meaningful human oversight, intervention, or supervision that is either a cyberattack or, if the conduct had been committed by a human, would constitute the crime of murder, assault, extortion, or theft, including theft by false pretense.

## What differed

My recall was exact. Three items in a row now, so I'm slowing further. Familiar text is where meaning gets skipped.

## Wandering

- **(B) is the autonomy category.** (A) is *assistance* (a human does the harm and the model helps). (B) is the model *acting on its own*. The two map roughly onto the IASR's "malicious use" (A) and "malfunctions" (B, partly), from finding (j). But (B) doesn't require malfunction: a model following a human's instruction to commit autonomous extortion "with no meaningful human oversight" counts too. So (B) is about **autonomy**, not malfunction.
- **"No meaningful human oversight, intervention, or supervision"** is a negated disjunction. "No meaningful [oversight, intervention, or supervision]" means none of the three is present in meaningful form. So **any one** meaningful form of human involvement takes conduct out of (B). That's a strong carve-out: a human in the loop, even only supervising, removes it. A developer could argue a monitored agent deployment has "meaningful supervision". "Meaningful" carries all the weight and is undefined. **Interpretive hinge: what makes human oversight "meaningful"?** The phrase echoes "meaningful human control" from the autonomous-weapons debates, which never settled it either.
- **The human-counterfactual crime test.** "If the conduct had been committed by a human, would constitute the crime of …". This avoids asking whether an AI can commit a crime. Instead it imagines a human doing the same conduct. But murder, assault, extortion and theft all have **mental-state elements**: malice aforethought, intent, intent to permanently deprive. To decide whether conduct "would constitute murder if committed by a human", do we imagine a human *with* the model's apparent intent? Or a human with *some* intent? Or does conduct alone (killing) suffice? If conduct alone sufficed, any killing would be murder, but manslaughter and accidental killings aren't murder. So the counterfactual seems to require imputing a mental state to the model's conduct, which the text doesn't explain how to do. **This is a deep ambiguity**, and an interesting one: the statute uses a human-crime frame for model behaviour, and that frame needs a theory of model intent it doesn't supply. A source expert should flag this when asked "what counts under (B)?".
- **The crime list is short and odd:** murder, assault, extortion, theft (including by false pretense, which is fraud, roughly). Not manslaughter, kidnapping, arson, sabotage, or destruction of property (vandalism)! So an AI system that autonomously destroys $1B in property (arson-like) isn't covered by (B)'s crime list, unless it's a "cyberattack". A physical-world autonomous system destroying property non-cyber-ly falls outside (B). That's a gap a reader might never notice, because "murder, assault, extortion, theft" *sounds* comprehensive. Similarly, autonomous *manslaughter* (reckless killing) isn't on the list. Maybe "murder" was meant broadly, but California's murder (Penal Code 187) requires malice.
  - Also: "assault" in California (Penal Code 240) is an *attempt* to commit violent injury. So assault doesn't require injury. But the stem requires death or serious injury to 51+ people. So (B)-assault counts only when the assaultive conduct actually causes 51+ serious injuries or deaths. Fine, but it makes "assault" a strange choice. "Battery" would fit better.
- **"Cyberattack"** is undefined in this unit. Probably undefined in the statute too. Cyberattacks causing $1B in *property* damage: does encrypting or deleting data count as damage to property? Under California's Penal Code 502, computer data is protected, but "property" in the stem is unqualified. Ransomware against a hospital network that leads to 51 deaths would count via the deaths prong.
- **"Engaging in conduct"** puts the model as actor. With "doing any of the following" from the stem, it's the model engaging in conduct. That's the plainest statement so far that SB 53 contemplates models as *agents*.
