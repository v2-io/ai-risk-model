## Wandering

- Output modalities only, not input. A model that *accepts* images and audio but outputs text reports "text". Input modalities matter for safety too (image-based jailbreaks, for instance), but they aren't required. Output modalities matter for harm (can it generate images, audio, actions?). Does "actions" count as a modality (tool calls, computer use)? An agentic model's main "output" may be actions. If developers report only "text", the report under-describes agentic capability. The statute's modality concept probably meant text/image/audio/video.
