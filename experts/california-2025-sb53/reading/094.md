## Wandering

- **The statute names the genres it codifies: "system card or model card".** It's an explicit lineage edge. The *model card* comes from Mitchell et al. (2019); the *system card* is lab practice (OpenAI's GPT-4 system card, March 2023; Anthropic's later system cards). So the transparency report needn't be a separate document. An existing system card that contains the listed items satisfies the law. **SB 53 legalizes the system card as the compliance vehicle.** For the corpus: a lab's system card published after January 2026 is, in part, a TFAIA compliance document. That changes what kind of claim it makes, a legally required statement now, potentially subject to false-statement liability.
- "Deemed in compliance" is a safe harbour, but only for the *placement* question. It doesn't excuse missing content.
- The practical effect: no new genre is created. Readers of system cards won't necessarily know which parts are legally required. A useful tagging task for later: for each lab system card in the corpus, mark which sections answer §22757.12(c)(1)/(2).
