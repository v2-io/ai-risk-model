# Unit 40 · L94 · p.3

> (b) "Artificial intelligence model" means an engineered or machine-based system that varies in its level of autonomy and that can, for explicit or implicit objectives, infer from the input it receives how to generate outputs that can influence physical or virtual environments.

## What differed

It matches my prediction word for word. It's California's standard AI definition (AB 2885, 2024), which descends from the OECD's revised 2023 definition of an AI system.

## Wandering

- **A model defined as a system.** "'Artificial intelligence *model*' means an engineered or machine-based *system* …". The OECD, and after it the EU AI Act Art. 3(1), use this formula to define an **AI system**. The EU then defines a **general-purpose AI model** separately, and treats a *model* as a component that is *integrated into* a system. California uses the system formula and gives it the label *model*. So:
  - **CA "artificial intelligence model" ≈ EU/OECD "AI system"** (same words, same definiens);
  - **CA "artificial intelligence model" ≠ EU "AI model"** (same label, different thing).

  This is a clean instance of the corpus problem in CLAUDE.md: one word, different things, and the same definition under different words. **A lexicon mapping that aligns on labels will mismap here, and one that aligns on definitions will map correctly.** It's also a lineage edge: OECD (2019, revised Nov 2023) → EU AI Act Art. 3(1) (2024) → CA AB 2885 (2024, Gov. Code §11546.45.5?) → SB 53 §22757.11(b). SB 53 restates it in full rather than cross-referencing, so it's an *embedded* copy, not a citation.
- Practically, the CA definition of "model" includes deployed systems with scaffolding, since a system with autonomy and objectives is more than weights. But "foundation model" and "frontier model" will presumably narrow to trained models. Then the compute threshold attaches to *training*, which is about the model in the weights sense. So the statute's "model" may slide between senses: system (this definition) and trained artifact (the compute threshold). **Watch for that slide**: when the frontier model is defined by training compute, is the referent the system or the weights?
- "Varies in its level of autonomy" is OECD phrasing meaning autonomy can be zero; it isn't a requirement. "For explicit or implicit objectives" covers both programmed goals and learned ones. "Infer from the input it receives" is the key inference criterion that separates AI from traditional software.
- This definition is so broad it covers almost any ML system. It matters only as the root of the chain: AI model → foundation model → frontier model.
