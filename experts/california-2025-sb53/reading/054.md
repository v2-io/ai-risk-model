# Unit 54 · L111 · p.4

> (e) (1) "Deploy" means to make a frontier model available to a third party for use, modification, copying, or combination with other software.

## What differed

My first prediction. The "(1)" confirms that a (2), an exclusion, follows.

## Wandering

- **Four kinds of availability:** use (API, chat), modification (fine-tuning), copying (weights release), and combination with other software (integration and scaffolding). So **open-weight release is deployment** (copying, modification), and so is API access (use). One verb covers both release modes, so there's no separate concept for open-weight release in SB 53. That matters: SB 53 doesn't treat open weights specially, at least in this definition. Compare SB 1047 debates, and the EU's open-source exemptions. A likely question: "How does SB 53 treat open-weight models?" Answer so far: releasing weights is deploying, with no special exemption visible. Watch for any later carve-out.
- **"A third party."** Internal use isn't deployment, since a developer using its own model isn't making it available to a third party. That fits the separate internal-use assessment regime (digest, u8). What about *affiliates*? Is an affiliate a third party? If Alphabet makes a DeepMind model available to Google Cloud customers, that's third-party deployment. If DeepMind makes it available to Google (an affiliate) for internal use, is that deployment? "Affiliate" is defined, but here it isn't used. So an affiliate is presumably a third party (a distinct person). Unless "frontier developer" is defined to include affiliates. **Watch: is intra-group availability deployment?**
- Contractors, red-teamers and evaluators: making a model available to a third-party evaluator (UK AISI, METR, Apollo) for testing is availability "for use" by a third party. So pre-deployment testing by outsiders would *be* deployment, unless (2) excludes it. I'd bet (2) excludes availability for evaluation, or development in some form.
- The definition is of the *act* of deploying. Transparency reports attach "before, or concurrently with, deploying a new frontier model" [recall]. So this definition fixes when the report is due.
